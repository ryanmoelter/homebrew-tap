# Ryan Moelter's Homebrew tap

```sh
brew install ryanmoelter/tap/wt
brew install ryanmoelter/tap/stack
```

Both come from [cli-tools](https://github.com/ryanmoelter/cli-tools).

```sh
brew install ryanmoelter/tap/plume
```

A cask for [Plume](https://github.com/ryanmoelter/plume). Upgrade with `brew upgrade --cask plume` — Plume has no self-updater, so this is the only update path.
